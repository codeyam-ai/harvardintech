## Brand mark (feeds `launch--images`)

The owner supplied `HIT_BrandGuidelines.pdf`. Its **full logo is unusable** — it
reads "HARVARD IN TECH" and the organisation is now *Harvard Alumni in Tech*, so
the guidelines predate the rename. Its palette is blue; the site is crimson.

**The H mark on its own is approved for use**, and replaces the Harvard shield in
the header. The same shape becomes the browser icon, which today is an unused
blue placeholder that no shell even links.

Geometry, measured off the guidelines (the photo-mask version gives a clean
silhouette; the lockup gives the overline bands). **One unit governs the mark:
the stem width, 47.** The bar, the gap beneath it and the crossbar are all that
same weight — which is what makes the white band plus the channel between the
stems read as a **T** in the negative space. That T is the point of the mark;
closing the gap destroys it.

| Band | Value |
|---|---|
| Overline bar | 47 |
| Gap beneath the bar | 47 — the T's crossbar |
| Stems above the crossbar | 73 — the T's stem, 53 wide |
| Crossbar | 47 |
| Stems below the crossbar | 55 |
| Stem width / channel | 46 / 53 |
| Overall | 145 × 269 (the H alone is 145 × 175) |

```svg
<svg viewBox="0 0 145 269" xmlns="http://www.w3.org/2000/svg" role="img" aria-label="Harvard Alumni in Tech">
  <path d="M0 0h145v47H0z M0 94h46v175H0z M99 94h46v175H99z M46 167h53v47H46z" fill="currentColor"/>
</svg>
```

`currentColor` so one file serves crimson on white, white on crimson and white on
ink without a second asset. Three rectangles, so it stays crisp at the 26px the
header uses.

**Still worth doing:** check this against the original vector artwork if it ever
turns up. It is measured, not traced, but it is measured from a raster.

**For Ben's HAA question:** the guidelines' own tagline is *"The official Harvard
alumni group dedicated to empowering its technology community."* The site wants to
say "The official Harvard Alumni Group for technology" — their own brand document
already uses that construction, which is useful evidence when he asks.
